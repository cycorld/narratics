# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Narratics very seriously. If you discover a vulnerability, please report it privately:

1. **Email:** Send details to `cycorld@martian.link` or `security@martian.link`.
2. **GitHub Security Advisories:** Submit a private vulnerability report via [GitHub Security Advisories](https://github.com/cycorld/narratics/security/advisories/new).

Please include:
- A description of the vulnerability.
- Steps to reproduce or a proof of concept.
- Affected components (engine-core, backend-sync, desktop, mobile-bridge).

We commit to acknowledging reports within **48 hours** and providing regular status updates until resolved.
